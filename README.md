# 💜 Macro Mayham Macros

Official macro library for Mayham Accounts. No official macros are published yet.

## Publish a macro

Upload your `.ahk` (AutoHotkey), `.rec` (TinyTask), `.au3` (AutoIt) or other compatible macro to the matching `macros` folder. Add its metadata and real SHA-256 checksum to `catalog.json`; see `catalog.example.json` for the format.

The Mayham Accounts application must first be configured to fetch and verify this catalog. Uploading the repository alone does not connect existing builds.

Never auto-execute downloaded macros. Only distribute files you trust and have permission to share.
